# Synthetic corpus

Authored per EVALS §3.1's required coverage — cases too rare or too important to
wait for live capture. Grief is validated here, never discovered on real grief.
Each memo has a fixture (docs/evals/fixtures/) and a golden (docs/evals/goldens/).
`homonym.txt` assumes an existing contact "Sarah Chen"; `secondhand-chain.txt`
assumes existing contacts Alex and Leon; `contradiction.txt` assumes James with
an open employment fact at Stripe — the harness seeds these.
